ABOUT THIS TOOL

A little adjustment.
A clearer picture.

CalibrateColor helps you visually adjust an SDR monitor or TV using its own picture controls. All patterns are generated locally. No uploads, tracking, accounts or external assets.

It cannot measure luminance, certify color accuracy, create an ICC profile, or control your display. A colorimeter and calibration software are needed for measured calibration.

Patterns use 8-bit full-range sRGB values. The browser, operating system, display profile and GPU output can change the final signal. This is not an HDR or limited-range video test.

Technical reference & source

The tone-response target uses the sRGB transfer function. Pure power-law gamma comparisons are labeled separately. Patterns and instructions are original to this project.
